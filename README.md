# 👗 VESTIQUE - متجر الملابس الحديث

متجر إلكتروني احترافي لبيع الملابس والأحذية والإكسسوارات، مع لوحة تحكم كاملة لإدارة المنتجات والطلبات.

## ✨ الميزات

✅ **واجهة مستخدم حديثة وجميلة**
- تصميم ريسبونسيف يعمل على جميع الأجهزة
- ألوان احترافية وتأثيرات بصرية جذابة
- سهل الاستخدام والتنقل

✅ **إدارة منتجات قوية**
- إضافة وحذف المنتجات بسهولة
- تحديد المقاس واللون والمادة
- إدارة المخزون
- نظام تقييمات وتقيمات العملاء

✅ **نظام فئات مرن**
- 6 فئات افتراضية (رجالي، نسائي، أطفال، أحذية، إكسسوارات، ملابس رياضية)
- إمكانية إضافة وحذف فئات جديدة

✅ **نظام الطلبات**
- تسجيل الطلبات الجديدة
- عرض جميع الطلبات والتفاصيل
- حالات الطلبات (قيد المعالجة، مُسلَّم، إلخ)

✅ **لوحة تحكم آمنة**
- تسجيل دخول محمي
- لوحة إحصائيات شاملة
- إدارة كاملة للمنتجات والطلبات

✅ **قاعدة بيانات SQLite**
- سهلة الإعداد والاستخدام
- تخزين آمن للبيانات

## 🚀 البدء السريع

### المتطلبات
- Python 3.7+
- pip

### التثبيت

1. **استنساخ أو تحميل المشروع:**
```bash
cd your_project_folder
```

2. **تثبيت المكتبات:**
```bash
pip install -r requirements.txt
```

3. **تشغيل التطبيق:**
```bash
python app.py
```

4. **الوصول للموقع:**
- 🌐 الموقع الرئيسي: `http://localhost:5000`
- 🔐 لوحة التحكم: `http://localhost:5000/admin`

## 🎨 الصفحات الرئيسية

### 1. الصفحة الرئيسية `/`
- عرض جميع المنتجات في شكل بطاقات جميلة
- البحث عن المنتجات
- تصفية حسب الفئة
- عرض التقييمات والآراء

### 2. لوحة التحكم `/admin`
**الميزات:**
- عرض إحصائيات المبيعات والمنتجات
- إدارة المنتجات (إضافة، حذف)
- إدارة الفئات (إضافة، حذف)
- عرض الطلبات الجديدة

**الروابط الرئيسية:**
- `/admin/products` - إدارة المنتجات
- `/admin/product/new` - إضافة منتج جديد
- `/admin/categories` - إدارة الفئات
- `/admin/orders` - عرض الطلبات

## 💾 قاعدة البيانات

يتم إنشاء قاعدة البيانات تلقائياً عند التشغيل الأول وتتضمن:

### جداول النظام:
- **products** - المنتجات
- **categories** - الفئات
- **orders** - الطلبات
- **order_items** - تفاصيل الطلبات
- **admins** - حسابات الأدمن

### البيانات الافتراضية:
- 8 منتجات نموذجية
- 6 فئات جاهزة
- حساب أدمن واحد

## 🔧 التخصيص

### تغيير اسم المتجر
في ملف `app.py`، ابحث عن:
```python
<a href="/" class="logo">VESTIQUE</a>
```
وغيّر `VESTIQUE` لاسم المتجر الخاص بك.

### تغيير كلمة مرور الأدمن
في ملف `app.py`، ابحث عن:
```python
admin_password = hashlib.sha256('admin123'.encode()).hexdigest()
```
وغيّر `admin123` بكلمة مرور قوية.

### تغيير الألوان
في ملف `app.py`، عدّل متغيرات CSS:
```css
--primary: #1a1a2e;    /* اللون الأساسي */
--accent: #e94560;     /* لون التركيز */
--light: #f8f9fa;      /* اللون الفاتح */
```

## 📊 مثال على إضافة منتج

1. ادخل لوحة التحكم `/admin`
2. اضغط على "إدارة المنتجات"
3. اضغط على "إضافة منتج جديد"
4. ملأ البيانات:
   - **الاسم**: تيشيرت قطني
   - **السعر**: 150
   - **الفئة**: رجالي
   - **المقاس**: S, M, L, XL
   - **اللون**: أسود, أبيض
   - **المادة**: قطن 100%
   - **الجنس**: رجالي
   - **الوصف**: تيشيرت عالي الجودة
   - **المخزون**: 50
5. اضغط "حفظ المنتج"
